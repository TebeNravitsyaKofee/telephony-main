
# Change Log
 
## [0.1.0] - 2025-08-10
_Тестовая версия._

### Added
- Реализовано получение внутренних линий со стороны АТС, отслеживание и редактирование состояний линий.
- Реализована возможность управления настройками подключения к АТС.
- Реализован базовый командный интерфейс.

## [0.1.1] - 2025-08-30
_Тестовая версия._

### Added
- Разделены отладочная и релизная конфигурации, добавлена отладочная версия сервера.
- Добавлена обработка ошибок при работе операторов connect() и SSL_new;

### Changed
- Функция SendMessage() теперь работает как с content-length-based, так и с chunked-encoded ответами.
- Улучшена очистка мусора при обработке ошибок.
- Улучшена надежность отправки запроса - учтена специфика работы библиотеки OpenSSL с неблокирующими сокетами, теперь SendMessage() отправляет запрос полностью.

## [0.1.2] - 2025-09-05
_Тестовая версия._

### Added
- Реализовано принятие событий с АТС по протоколу HTTP.
- Реализована обработка входящего звонка и отслеживание состояний звонка в реальном времени

## [0.1.3] - 2025-09-21
_Тестовая версия._

### Added
- Реализовано отслеживание звонков в режиме реального времени через терминал
- Реализован командный интерфейс для подключение к PostgreSQL базе
- Реализована запись звонков в PostgreSQL базу

### Changed
- Сервер теперь работает в отдельном потоке, не блокируя основной поток программы
- Процесс обработки звонков отделен от процесса работы с интерфейсом

### Fixed
- Теперь сервер обрабатывает ping и key события со стороны АТС

## [0.1.4] - 25.09.2025
_Тестовая версия._

### Changed
- Изменено отображение активных звонков в терминале звонков

### Fixed
- Теперь время и дата корректно пишутся в PostgreSQL
- Теперь сервер полностью отсоединяется от родительского процесса и корректно работает в фоне
