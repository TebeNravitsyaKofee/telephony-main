# Телефония
Проект предназначен для отслеживания текущих телефонных звонков в облачной АТС Mango Office и записи информации о звонке в базу данных. Установленный сервер телефонии взаимодействует с телефонной станцией посредством API, разработанного сотрудниками Mango Ofiice. В настоящий момент проект находится на стадии разработки.

## Технологии
- [OpenSSL](https://www.openssl.org/)
- [VSCode](https://code.visualstudio.com/)

## Использование
Проект доступен на debian-linux платформах.
Проект доступен для тестов, устанавливается разработчиком индивидуально по запросу.

## Разработка
### Требования
Для работы проекта необходимо установить библиотеку OpenSSL, а также иметь настроенный и готовый к работе PostgreSQL.

Для участия в разработке проекта необходимо также установить библиотеку nlohmann/json, с порядком установки можно ознакомиться по ссылке: https://github.com/nlohmann/json.

Проект использует ODBC драйвера для работы с базой данных, рекомендуется использовать их и при дальнейших интеграциях новых БД.

### Какую из предоставленных кофигураций использовать?
В проекте используются две конфигурации запуска проекта - app_debug и app_release.
Для разработки и отладки рекомендуется использовать app_debug, в ней реализован вывод полной отладочной информации в консоль - в лог информация попадает не полностью в обеих сборках.

### Тестирование
Проект проходил нагрузочное тестирование при помощи k6 (https://k6.io/), скрипты для тестирования доступны по требованию.
